# Automatic pet feeding and monitoring system 

Meowton is a system that will automaticly feed your pet and create nice graphs.

You can use it to monitor your pet or to put it on a diet.

I use it for my cats but you can also use it for dogs or perhaps other animals.

For more info look at the wiki: https://github.com/psy0rz/meowton/wiki
